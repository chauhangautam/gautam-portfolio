# Gautam Chauhan — Angular Portfolio

Requires Node.js 20+.

    npm install
    npm start        # http://localhost:4200
    npm run build    # output in dist/gautam-portfolio

Edit your details in src/app/app.component.ts. Styles are in src/styles.css.
